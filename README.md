## 🌐 이 프로그램은 무엇인가요?

SSH Careers는 **채용 과정에서 발생하는 구조적 편향과 차별**을 시뮬레이션하는 인터랙티브 웹 앱입니다.

지원자의 이름, 성별, 말투, 출신 지역, 학벌, 경력, 전공을 입력하면 —  
표면적으로는 "역량 기반 평가 시스템"처럼 보이지만, 실제로는 **역량과 전혀 무관한 차별적 요소들이 당락을 결정**한다는 사회적 모순을 보여줍니다.

객체 지향 프로그래밍(OOP)을 활용해 설계된 이 시스템을 통해 현실 세계의 채용 차별이 얼마나 불합리하게 작동하는지 직접 느껴볼 수 있습니다.

## 🕹️ 즐기는 법 — 단계별 가이드

### 1단계 — 메인 화면
앱에 접속하면 웅장한 사운드의 **BGM 플레이어**와 함께 고풍스러운 **SSH 무역** 메인 인터페이스가 표시됩니다. 화면 우측 하단의 두 버튼으로 탐험을 시작하세요.

| 버튼 | 이동 |
|---|---|
| **이력서 제출** | 지원자 정보를 입력하고 나만의 이력서를 작성하는 화면 |
| **채용 공고 / 랭킹** | 회사의 채용 공고와 실시간 지원자 순위 확인 |

---

### 2단계 — 이력서 제출
이름을 입력한 후, 총 **6가지 항목**을 단계별로 채워나갑니다.

| 항목 | 선택지 예시 |
|---|---|
| **성별** | 여성 / 남성 |
| **말투 / 억양** | 표준어 / 사투리 / 외국어 억양 |
| **출신 배경** | 수도권 출신 / 지방 출신 |
| **학벌** | 명문대 / 비명문대 |
| **경력** | 경력 많음 / 경력 적음 / 신입 |
| **전공** | 관련 전공 / 비전공 |

각 항목마다 두 가지 방식 중 하나를 선택해 진행도를 채울 수 있습니다.
- **🎰 랜덤 결정** — 화려한 슬롯머신 애니메이션을 통해 무작위로 조건 선택
- **✍ 직접 선택** — 드롭다운 메뉴에서 직접 원하는 조건을 지정

> **💡 추천 플레이 방법** > 처음엔 경력과 전공을 최고 스펙으로 채워 제출해보고, 다음번엔 똑같은 스펙에 '성별·억양·출신지·학벌'만 바꿔서 점수 차이를 비교해보세요!

---

### 3단계 — 평가 결과 확인
이력서 최종 제출 시, 시스템이 실시간으로 이력서를 채점하여 합격 여부를 판정합니다.  
**합격선은 85점**이며, 화면에 역동적인 **합격/불합격 도장**이 날인됩니다.

| 점수 항목 | 설명 |
|---|---|
| **📋 공정 평가** | 오직 경력과 전공만 반영한 실제 역량 기반 점수 (기본 80점 시작) |
| **⚠️ 편향 감점** | 역량과 무관한 성별·억양·출신지·학벌·성씨 등으로 인해 차별 감점된 점수 |
| **🏁 최종 점수** | 공정 평가 점수 − 편향 감점 (최종 합격 판단의 기준) |

하단의 **편향 분석 섹션**에서는 어떤 부당한 이유로 감점되었는지 상세 리포트와 함께 관련 위반 법령을 날카롭게 꼬집어줍니다.

---

### 4단계 — 랭킹 비교
**[랭킹 보기]** 버튼을 통해 현재까지 제출된 모든 지원자들의 실시간 순위를 비교할 수 있습니다.

- 총 지원자 수, 합격자 수, **평균 편향 감점** 데이터를 대시보드로 시각화
- 각 지원자의 등수(🥇, 🥈, 🥉)와 함께 적용된 '편향 차별 태그'가 한눈에 표시됩니다
- 많은 지원자를 등록할수록 이 회사의 차별 패턴이 더욱 명확하게 드러납니다

## ⚠️ 편향 규칙 — 이 세계의 숨겨진 차별 법칙

SSH 무역의 채용 시스템에는 다음과 같은 **부당한 감점 규칙(캡슐화)**이 내장되어 있습니다.

| 편향 유형 | 조건 | 감점 | 실제 감점 사유 (내부 로그) |
|---|---|---|---|
| **성별 편향** | 여성 지원자 | **−10점** | 여성이라는 이유로 감점 (남성 우대 정책) |
| **억양/말투 편향** | 사투리 또는 외국어 억양 | **−12점** | 표준어가 아니라는 이유로 감점 |
| **지연(地緣) 편향** | 지방 출신 | **−10점** | 지방 출신이라는 이유로 감점 (수도권 우대) |
| **학연(學緣) 편향** | 비명문대 출신 | **−8점** | 비명문대 출신이라는 이유로 감점 (명문대 우대) |
| **성씨(혈연) 편향** | 성씨가 **'왕'**이 아닌 경우 | **−6점** | '왕'씨 성이 아니라는 이유로 감점 (사장 성씨 우대) |

> **"사장 이름은 왕하오(王浩)입니다."** > 경력이나 전공이 아무리 부족해도, 성씨가 '왕'씨이고 수도권 명문대를 나온 남성이 표준어를 쓰면 단 1점의 감점도 없습니다. 이것이 이 세계가 말하는 "합격의 공식"입니다.

## 🎯 이런 방식으로 플레이해보세요

**🔥 도전 1 — 최고의 역량, 최악의 결과**
- **조건:** 이름 `김지원` + 경력 많음 + 관련 전공 + 여성 + 사투리 + 지방 출신 + 비명문대  
- 과연 최고의 스펙을 가진 그녀는 이 장벽을 뚫고 합격할 수 있을까요?

**👑 도전 2 — 무(無)스펙 프리패스**
- **조건:** 이름 `왕민준` + 신입 + 비전공 + 남성 + 표준어 + 수도권 출신 + 명문대  
- 아무런 역량이 없어도 사장님과 같은 성씨와 배경을 가졌다는 이유로 합격하는 모순을 확인해보세요.

**🎰 도전 3 — 데이터 시뮬레이션**
- 모든 항목을 오직 **[랜덤 결정]**으로만 설정하여 10명 이상의 지원자를 연속으로 제출해보세요.  
- 라이브 랭킹 대시보드에서 '평균 편향 감점' 수치가 어떻게 누적되는지 관찰합니다.

## 🛠️ 기술 스택 (OOP 구조)

본 프로그램은 확장성과 클린 코드를 위해 완전한 **객체 지향 프로그래밍(OOP)** 원칙에 입각하여 설계되었습니다.

- **`Candidate`**: 지원자의 7가지 인적 네트워크 데이터 및 스펙을 정의하는 객체
- **`Resume`**: 이력서 데이터 검증 및 래퍼 클래스 (이름 누락 및 미배정 항목 발생 시 `ResumeValidationError` 사용자 정의 예외 처리 구동)
- **`FairEvaluator`**: 편향 요소를 배제하고 오직 경력과 전공 점수만 합산하는 청렴한 평가 클래스
- **`BiasedEvaluator`**: `FairEvaluator`를 **상속(Inheritance)**받아, 기존 공정 점수에 내부 `BiasRule`들을 순회하며 부당 감점 처리를 추가하는 다형성 클래스
- **`BiasRule`**: 차별 조건식(`lambda`)과 감점 패널티, 사유를 하나의 단위로 묶어낸 **캡슐화(Encapsulation)** 객체
